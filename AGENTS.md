# AGENTS.md

AllyMailer Symfony — Symfony integration of the AllyMailer PHP SDK (`allymailer/allymailer-sdk`) for the AllyMailer transactional email Web API (Web API 1.90).

## Working on this repository

- **Generated code.** The whole package is generated by the AllyMailer team from the AllyMailer Web API OpenAPI spec (Web API 1.90): sources, docs, README.md and this file. Do not hand-edit it: the next release replaces the content of this repository. Report problems and requests in the issues of this repository (https://github.com/allymailer/allymailer-symfony).
- **Build and check:**

  ```bash
  composer validate
  composer install
  ```

- **Source label.** Every request carries the query parameter `platform=symfony.2.0.0,php-sdk.2.0.0` (this package, then the SDK it is built on).
- **Tests.** Before a release the generator installs the package into a test app of Symfony and checks the client, the webhook endpoint and the mailer against a mock of the API: no real API key, no real sends.
- **Release.** The version (2.0.0 in composer.json) and the tag `v2.0.0` come from the generator; README.md states the Web API version the release was generated from.
- **Secrets.** Never commit API keys; the examples read `ALLYMAILER_API_KEY` from the environment.

## Integrating AllyMailer with this package

Full guide: [README.md](README.md). Symfony integration of the [AllyMailer PHP SDK](https://github.com/allymailer/allymailer-php-sdk) (`allymailer/allymailer-sdk`): the API client in the service container, a webhook endpoint with signature check, a Symfony Mailer transport that sends through `email/send`.

Install:

```bash
composer require allymailer/allymailer-symfony-bundle
```

Requirements: PHP 8.1+, Symfony 6.4 / 7.x.

Rules that generated code must follow:

- Server-side only. Read the API key from `ALLYMAILER_API_KEY`; never put it in browser or mobile code, never commit it.
- Base URL `https://cp.allymailer.com/ua/transactional/api/v1`; every method is POST with a JSON body; auth header `X-API-KEY`. The package does all of it.
- First email without DNS: `domain/get-sandbox-domain` → `confirmed-email/create` (the user clicks the link within 48 hours) → `email/send` from `noreply@<sandbox-domain>` to the confirmed address. Account API key only; up to 10 confirmed addresses, 100 emails a day; the domain expires after 31 days.
- Never ship a sandbox domain as the production sender (it is not in `domain/list`); read `from_email` from config. Production needs a verified domain: `domain/get-dns-records` → DNS records → `domain/validate-verification-record`, `domain/validate-dkim` → `domain/list`.
- Set `message.idempotence_key` on retryable sends; retry network errors, `429` and `5xx` with backoff, not other errors unchanged. Up to 500 recipients and 10 MB per request, each attachment up to 7 MB; always `body.html` or `body.plaintext`.
- Delivery events via webhook (`webhook/set`), not polling; the webhook endpoint of this package checks the `auth` signature of every notification.
- Keep the default unsubscribe and tracking behaviour; changes go through AllyMailer support.
- Do not invent methods or fields. Check the [README](README.md), the [API reference](https://docs.allymailer.com.ua/ua/web-api-ref) or [llms.txt](https://docs.allymailer.com.ua/llms.txt).

### Configuration

The API key goes to `ALLYMAILER_API_KEY`.

```yaml
# config/bundles.php: AllyMailer\Wrapper\AllyMailerBundle::class => ['all' => true]

# .env
#   ALLYMAILER_API_KEY=YOUR_API_KEY
#   ALLYMAILER_HOST=cp.allymailer.com
#   MAILER_DSN=allymailer+api://default

# config/packages/allymailer.yaml (optional, these are the defaults)
allymailer:
    api_key: '%env(ALLYMAILER_API_KEY)%'
    host: '%env(default::ALLYMAILER_HOST)%'
    webhook:
        path: '/allymailer/webhook'

# config/routes/allymailer.yaml
allymailer_webhook:
    resource: .
    type: allymailer_webhook
```

| Option | Environment variable | Default | Description |
|---|---|---|---|
| `allymailer.api_key` | `ALLYMAILER_API_KEY` |  | User or project API key (required). |
| `allymailer.host` | `ALLYMAILER_HOST` | `cp.allymailer.com` | API host (datacenter: `cp.allymailer.com`) or a full base URL. |
| `allymailer.timeout` | `ALLYMAILER_TIMEOUT` | `30` | Request timeout, seconds. |
| `allymailer.webhook.key` | `ALLYMAILER_WEBHOOK_KEY` |  | API key the webhooks are signed with (the key of the user/project of the webhook), if it differs from the API key. |
| `allymailer.webhook.path` | `ALLYMAILER_WEBHOOK_PATH` | `/allymailer/webhook` | Path of the webhook endpoint. |

### Sending mail

Messages of the Symfony Mailer go through [email/send](https://docs.allymailer.com.ua/ua/web-api-ref#email-send): from, to/cc/bcc, reply-to, subject, HTML and text parts, attachments, inline images and `X-*` headers.

```php
use Symfony\Component\Mailer\Header\MetadataHeader;
use Symfony\Component\Mailer\Header\TagHeader;
use Symfony\Component\Mime\Email;

$email = (new Email())
    ->from('shop@example.com')
    ->to('user@example.com')
    ->subject('Order shipped')
    ->html('<p>Your order is on its way</p>');
$email->getHeaders()->add(new TagHeader('orders'))->add(new MetadataHeader('order_id', '42'));

$mailer->send($email);
```

### Webhooks

The endpoint answers `GET` with 200 OK (the URL check of [webhook/set](https://docs.allymailer.com.ua/ua/web-api-ref#webhook-set)) and accepts the `POST` notifications: it checks the `auth` field (MD5 of the request body in which the `auth` value is replaced by the API key), answers 401 to a wrong signature, and passes the notification and each of its events to the application.

```php
use AllyMailer\Wrapper\Event\WebhookEventReceivedEvent;
use Psr\Log\LoggerInterface;
use Symfony\Component\EventDispatcher\Attribute\AsEventListener;

#[AsEventListener]
final class EmailStatusListener
{
    public function __construct(private readonly LoggerInterface $logger)
    {
    }

    public function __invoke(WebhookEventReceivedEvent $e): void
    {
        $data = $e->event->eventData;
        $this->logger->info('AllyMailer event', ['name' => ($n = $e->event->eventName) instanceof \BackedEnum ? $n->value : $n, 'email' => $data?->email,
            'status' => ($s = $data?->status) instanceof \BackedEnum ? $s->value : $s]);
    }
}
```

Register the URL of the endpoint with `webhook/set`, e.g. `https://example.com/allymailer/webhook`.
